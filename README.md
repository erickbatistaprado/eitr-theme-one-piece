# One Piece theme for Eitr

A dark [Eitr](https://eitr.info) theme with One Piece art: blood moon red on dark crimson, with 9 wallpapers.

![Preview](one-piece/preview.png)

## Install

Open the Eitr Store, choose Themes, and search for One Piece.
